# DashboardPage
The admin home screen, composed from Sidebar, LibraryHeader, StatTile, MemberStrip, RankedList, ActivityFeed and CheckoutBar.

Layout: a three-column grid (232px sidebar · fluid main · 300px activity) with the CheckoutBar spanning the bottom. Main content stacks with `space-6` gaps. Below 1200px the activity panel collapses behind a button; below 900px the sidebar becomes a top bar.
