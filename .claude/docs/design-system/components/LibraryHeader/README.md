# LibraryHeader
The top of the dashboard: who you are managing and how big it is, in one glance.

- A round monogram (`brand` disc with a `brand` ring), the eyebrow "Library", the name in `display`, and three live counts (copies, members, active loans).
- `la-switch` switches between the two libraries; the whole dashboard follows the selection.
- Decorative book spines on the right are built from `brand`, `sidebar`, `gold`, `ink` and `brand-soft`; they hide on narrow screens.

**Consumer provides:** library name and initials, the three counts, the list of libraries and the selected one.

**Do** keep the counts live and rounded with thousands separators. **Don't** add more than one secondary action here.
