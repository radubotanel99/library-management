# MemberStrip
A horizontal row of round member avatars with name and loan count.

- 72px circles with initials in the serif face; tints rotate through `brand-soft`, `warning-soft`, `success-soft`, `neutral-soft` (picked from the member id, so each person keeps one colour).
- Name in `title`, count in `caption`.

**Consumer provides:** up to 5 members (initials, name, count, link).

**Do** use initials when there is no member photo. **Don't** use the avatar tint to mean anything; it is decoration.
