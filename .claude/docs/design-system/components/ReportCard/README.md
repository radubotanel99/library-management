# ReportCard
A square-ish card that opens a report or a saved list (New arrivals, Due this week, Overdue, Lost & damaged, Monthly report).

- The art block carries a tiny eyebrow and the headline figure in serif; variants: default (`brand`), `--soft`, `--danger`, `--ink`, `--gold`.
- Title in `title`, one-line description in `caption`.

**Consumer provides:** variant, eyebrow, headline figure, title, description, link.

**Do** reserve `--danger` for the Overdue card. **Don't** put more than five cards in the row.
